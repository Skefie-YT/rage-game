# TOWER OF REGRET

A Jump-King-style vertical rage climber built with pure HTML5 Canvas, CSS, and Vanilla JavaScript (plus synthesized Web Audio API sound effects — zero external assets).

## Controls
- **Walk / Aim Jump:** `A` / `D` or `←` / `→`
- **Charge & Release Jump:** Hold & release `Space` / `W` / `↑` (or use on-screen touch controls on mobile)
- **Mute Audio:** `M`
- **Restart Run:** `R`

## Features
- **4 Distinct Zones:** The Mossy Dungeon, The Windy Spire, The Icy Peaks, and The Golden Heaven
- **Rage Hazards:** Slippery ice, crumbling ledges, spring pads, moving platforms, wind gusts, angry bonk orbs, fake ledges, and a troll checkpoint
- **Hardcore Mode:** Toggle off the jump power bar if you hate yourself
- **Zero-Dependency Static Site:** Runs directly on GitHub Pages

## Hosting on GitHub Pages
1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select the **`main`** branch and **`/ (root)`** folder, then click **Save**.
